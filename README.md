# FutureLAB Obsidian Plugins

内部自研 Obsidian 插件合集。

## 插件列表

- **auto-frontmatter** — 自动管理文档属性（Properties）
- **file-auto-upload-plugin** — 文件自动上传到腾讯云 COS

## 安装

1. clone 本仓库
2. 进入对应插件目录执行 `pnpm install && pnpm build`
3. 将构建产物（main.js、manifest.json、styles.css）复制到 Obsidian vault 的 `.obsidian/plugins/插件名/` 目录
4. 重启 Obsidian，在设置中启用插件
