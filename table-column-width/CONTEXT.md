# Table Column Width

让 Obsidian 原生 markdown 表格告别 auto 布局：所有表格以固定布局渲染，列宽可按列拖动调整，且宽度数据随笔记文件多设备同步。

## Language

**固定布局 (Fixed Layout)**:
表格的渲染模式：每列有明确像素宽度，文字折行，总宽超出容器时横向滚动，窄于容器时左对齐留白不拉伸。插件下所有原生 markdown 表格一律以此模式渲染。
_Avoid_: auto 布局、自适应布局

**标记行 (Marker Line)**:
位于表格正上方的一行 HTML 注释（`<!-- colwidths: 120,96,180 -->`），按列序号记录各列像素宽度。它既是持久化数据，也是开关：删除它，表格恢复原生行为。
_Avoid_: 注释行、宽度注释、元数据行

**冻结 (Freeze)**:
把一张表格从 auto 布局切换为固定布局、为每列赋予明确像素宽度的动作。分为「内存冻结」（只影响显示）和「落盘」（写入标记行）。
_Avoid_: 固定、锁定

**懒冻结 (Lazy Freeze)**:
持久化策略：历史表格首次渲染时只做内存冻结，不修改文件；用户首次拖动某列时才把整表宽度写入标记行。
_Avoid_: 立即写入、冻结即写入

**表头比对 (Header Reconcile)**:
表格结构变化（增删列）时，用表头文本序列做 diff 算出变化位置，同步维护标记行中宽度数组的过程。新插入列默认 120px。
_Avoid_: 列匹配、序号对齐

**拖动手柄 (Drag Handle)**:
列右边缘的拖拽热区，拖动它只改变本列宽度，不影响其他列。最小列宽 40px，新列默认 120px。仅桌面端可用；移动端只应用已存宽度，不显示手柄。
_Avoid_: 拖拽条、分隔条
